# Security Policy — LifeOS

## 🇮🇹 Segnalare una vulnerabilità
- **Non aprire issue pubbliche per segnalazioni di sicurezza.** Usa *Security → Report a vulnerability* (GitHub Security Advisory) oppure invia un'email direttamente a `fbxmano@gmail.com`.
- Fornisci: descrizione dettagliata, passi di riproduzione, versione software, potenziale impatto sulla riservatezza dei documenti e dati personali.
- Prima risposta confermata entro **7 giorni**; politica di divulgazione coordinata (coordinated disclosure) entro **90 giorni** dalla presa in carico.

## 🇬🇧 Reporting a Vulnerability
- **Do not open public issues for security vulnerabilities.** Submit via GitHub Security Advisories (*Security → Report a vulnerability*) or email `fbxmano@gmail.com`.
- Please include: comprehensive summary, reproduction steps, version tested, and estimated impact on personal document security and privacy.
- Initial acknowledgement within **7 days**; coordinated disclosure timeline of **90 days** from verified report.

## Versioni supportate / Supported Versions
Viene supportata attivamente solo l'ultima versione minor/patch rilasciata su `main`. /
Active security maintenance covers the latest minor/patch release on `main`.
