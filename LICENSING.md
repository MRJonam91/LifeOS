## 🇮🇹 Perché questa scelta
- **AGPL-3.0**: protegge la sovranità dei dati personali e amministrativi. Chiunque modifichi o integri LifeOS per erogarlo come servizio web o cloud proprietario deve rilasciare il codice sorgente migliorato alla comunità.
- **Licenza commerciale**: consente ad aziende welfare, banche, assicurazioni e software house di integrare LifeOS in soluzioni commerciali o piattaforme proprietarie senza vincoli di copyleft.
- **CLA**: essenziale affinché l'autore originale possa offrire la licenza commerciale e preservare la possibilità di una cessione strategica (full IP buyout).
- **Header SPDX**: ogni file sorgente include l'header SPDX con autore e anno di rilascio.

## 🇬🇧 Why this choice
- **AGPL-3.0**: safeguards personal data sovereignty. Anyone modifying or extending LifeOS as a web or cloud service must contribute improvements back to the community under equal terms.
- **Commercial license**: enables fintech, insurtech, enterprise welfare, and consumer software providers to embed LifeOS in proprietary platforms without copyleft constraints.
- **CLA**: critical so the author can grant commercial exceptions and preserve full intellectual property transferability.
- **SPDX headers**: each source file includes a standard SPDX identifier with copyright declaration.
