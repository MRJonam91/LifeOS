# Codice di condotta / Code of Conduct

Questo progetto adotta il **Contributor Covenant 2.1** / This project adopts the **Contributor Covenant 2.1**:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## 🇮🇹 In breve
Rispetto reciproco, linguaggio inclusivo, feedback costruttivo e zero molestie. Comportamenti non conformi
possono comportare richiami formali, sospensione o espulsione permanente dal repository.

## 🇬🇧 In short
Mutual respect, welcoming language, constructive critique, and zero tolerance for harassment.
Unacceptable conduct may result in warnings, temporary bans, or permanent exclusion.
